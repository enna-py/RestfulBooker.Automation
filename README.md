# RestfulBooker Automation Framework

Automation framework for API and UI testing using .NET 8.

## Technology Stack

- .NET 8
- NUnit
- RestSharp
- Playwright
- Serilog

## Architecture

```
RestfulBooker.Automation
│
├── RestfulBooker.Api
├── RestfulBooker.Core
├── RestfulBooker.Data
├── RestfulBooker.UI
└── RestfulBooker.Tests
```
